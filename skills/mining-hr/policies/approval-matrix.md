# Approval Matrix Template

| Action | Default risk | Required approval |
|---|---|---|
| HR information lookup | Low | None if authorized |
| Leave | Medium | Supervisor / configured approver |
| Overtime | Medium | Authorized supervisor + payroll process |
| Incentive / ritase calculation | Medium (High if over threshold or recurring anomaly) | Authorized supervisor + payroll process |
| Roster change | Medium | Site/supervisor approval |
| Recruitment shortlist | Medium | Hiring manager |
| Final hiring | High | Authorized hiring manager |
| Mobilization / demobilization | Medium | Site HR / supervisor approval before movement |
| Offboarding (resignation, contract end, retirement) | Medium | Authorized HR |
| HR document issuance (standard, e.g. working certificate) | Low | Authorized HR |
| HR document issuance (disciplinary/compensation content) | High | Inherits source case's approval |
| Compensation change | High | Authorized HR/management |
| Promotion/demotion | High | Authorized management |
| Disciplinary outcome | High | Authorized HR/management |
| Termination | High | Authorized HR/management |
| Industrial-relations settlement | High | Authorized management/legal/HR |
| Medical/fitness decision | High | Authorized occupational-health process |

Replace this template with the company's actual delegation-of-authority matrix before production use.
